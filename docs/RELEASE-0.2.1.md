# GuitarRemedy 0.2.1 — Easier to follow

Open a lesson and start playing: the page now gives you one short instruction at a time. Next and Previous controls let you move at your own pace, and your current step saves automatically.

The first 14 lessons have handwritten steps for string names, fretting, open chords, strumming, pentatonic patterns, melody, and power chords. The strumming lesson includes a count-by-count visual guide. Unfamiliar terms such as fret, open string, BPM, bar, root, and phrase have plain-English explanations inside the lesson.

The goal, practice steps, guitar map, and self-check take priority. Longer practice sessions, theory, and path navigation remain available in expandable sections. A lesson number is a place in the path, not a deadline.

This update also corrects the Am-to-E shape explanation, makes power-chord finger positions explicit, and removes stale instructions from the generated coaching copy. Existing lesson notes, checkboxes, reviews, and completions are preserved.

Validation: 293 frontend tests, production builds, Rust tests, and browser checks at desktop and phone widths. Android is a debug APK for sideloading. Windows supports the signed in-app updater under About → Check for updates.

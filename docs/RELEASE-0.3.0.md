# GuitarRemedy 0.3.0 — Ten languages

Now available in Spanish, French, German, Portuguese (Brazil), Italian, Russian, Polish, Japanese, Korean and Chinese (Simplified). Apps use your system language by default; change it any time in Settings → Language.

Your lesson progress, notes, reviews, and saved tabs carry over unchanged. Android is a debug APK for sideloading. Windows installs update in place via About → Check for updates.
